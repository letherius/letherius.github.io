Web Development Skills

WEBD 225 has given me more practice with the tools that go into building and maintaining a website. I had some experience with web development before this course, but the assignments helped me get more comfortable using these tools together.

The areas below are some of the skills I've worked with throughout the course. I still have more to learn, but I've gotten better at understanding how each part affects the finished website.

Skills I've Practiced

I've used HTML to organize page content and CSS to control layout, fonts, spacing, images, and other parts of the design. I've also worked with CSS Grid and responsive layouts.

I've used Bootstrap for navigation, responsive columns, carousels, cards, buttons, and other components that make it easier to build a page that works across different screen sizes.

GitHub has been a big part of this course. I've practiced creating branches, committing changes, opening pull requests, and using GitHub Pages to view a live version of my work.

I've learned more about making pages adjust to different screen sizes instead of only designing for a desktop computer. This includes flexible layouts, responsive images, Bootstrap columns, and media queries.
